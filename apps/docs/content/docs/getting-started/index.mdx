## Ordem recomendada

1. Leia a [motivação arquitetural](/docs/getting-started/why-better-effect) para entender o que
   fica explícito e por quê.
2. Estude o [modelo mental](/docs/getting-started/mental-model) antes de escolher APIs de UI.
3. Faça a [instalação](/docs/getting-started/installation) somente dos packages que o seu projeto
   precisa.
4. Siga a [primeira feature](/docs/getting-started/first-feature) escrevendo o código no seu
   próprio composition root.

Se você já conhece a arquitetura e quer copiar um fluxo completo, vá direto
para a primeira feature. Se veio de um state manager Flutter, leia também o
[guia de MVVM](/docs/guides/flutter-mvvm).
