Depois do primeiro fluxo, estes guias ajudam a tomar decisões que normalmente
causam bugs em produção: tratamento de falhas, concorrência, ownership de
resources, contexto por execução, observabilidade, integração Flutter, testes e
validação arquitetural.

O guia Flutter é deliberadamente transversal: ele começa no `Effect` do core e
mostra como Runtime, scopes, Commands, ViewModels e widgets formam uma única
arquitetura. Use-o quando a dúvida for “como as peças se encaixam?”; use os guias
de Command/feature/testing quando precisar aprofundar uma área específica.
