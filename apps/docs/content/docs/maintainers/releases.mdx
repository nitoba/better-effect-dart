---
title: Releases independentes
description: Publique cada package sem acoplar versões
---

Cada package possui sua própria versão, changelog, dry-run e workflow. Use tags
com prefixo do package:

| Package | Tag |
| --- | --- |
| `better_effect` | `better_effect-v{{version}}` |
| `better_effect_flutter` | `better_effect_flutter-v{{version}}` |
| `better_effect_analyzer` | `better_effect_analyzer-v{{version}}` |

Exemplo:

```bash
git tag better_effect-v0.1.1
git push origin better_effect-v0.1.1
```

O pub.dev precisa ser configurado uma vez no Admin de cada package para aceitar
o repositório e o padrão de tag correspondentes. O GitHub Actions usa OIDC,
sem token de publicação de longa duração.

Consulte o [runbook completo](https://github.com/nitoba/better-effect-dart/blob/main/.github/RELEASE.md).
