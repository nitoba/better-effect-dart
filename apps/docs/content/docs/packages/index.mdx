Os três packages têm responsabilidades diferentes e versões independentes.
Comece pelo core quando a lógica não precisa de Flutter; adicione a integração
Flutter na borda de apresentação e mantenha o analyzer como tooling de
desenvolvimento.

<Cards>
  <Card title="better_effect" href="/docs/packages/better_effect" description="Runtime Dart com Effects, Modules, recursos, scopes e falhas tipadas." />
  <Card title="better_effect_flutter" href="/docs/packages/better_effect_flutter" description="Commands, ViewModels, bootstrap e widgets para projetar o Runtime na UI." />
  <Card title="better_effect_analyzer" href="/docs/packages/better_effect_analyzer" description="Plugin do Analysis Server e CLI para verificar código e grafo de Modules." />
</Cards>
